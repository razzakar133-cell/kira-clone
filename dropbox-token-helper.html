Dropbox সিক্রেট — কপি করে নাও

নিচের ৩টা ভ্যালু Cloudflare-এ kira-oauth → Settings → Variables → Add Secret-এ বসাতে হবে।

DROPBOX_CLIENT_ID
DROPBOX_CLIENT_SECRET
DROPBOX_REFRESH_TOKEN

Dropbox Refresh Token নেওয়ার পাতা

ধাপ ১: Dropbox অ্যাপের App key নিচে বসাও। তারপর Authorize বোতামে চাপ দাও — নতুন ট্যাবে Dropbox খুলবে, Allow চাপো। যে পাতায় কোড দেখাবে, কোডটা কপি করে নিচের Code ঘরে বসাও।

Authorize (Allow চাপতে হবে)
ধাপ ২: Code আর App secret বসিয়ে Refresh token নাও চাপো। পরের পাতায় JSON লেখা আসবে — তার ভেতরে "refresh_token"-এর পাশের লম্বা লেখাটাই তোমার refresh token, কপি করে নিও।
